# ByteRunner — Downloads

Installer downloads for **[ByteRunner](https://christianoleson.com/byterunner)** — an interactive
scratchpad for the JVM. Write Kotlin, Java, Groovy, or Scala and see the results instantly: tables,
trees, and charts instead of a wall of text, with built-in database connectivity, debugging, and testing.

## Download

Grab the latest installer from **[Releases](https://github.com/Christian-Oleson/ByteRunner-releases/releases/latest)**:

- `ByteRunner-<version>-Setup.exe` — recommended for most users
- `ByteRunner-<version>.msi` — for enterprise / managed installs (GPO)

ByteRunner checks for updates on startup and will let you know when a new version is available.
